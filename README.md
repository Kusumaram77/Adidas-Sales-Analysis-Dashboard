# Adidas-Sales-Analysis-Dashboard
Interactive Adidas Sales Analysis Dashboard built using Power BI.


## Overview
An interactive sales analysis dashboard developed using Microsoft Power BI to analyse Adidas sales performance and generate business insights.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Key Features
- KPI tracking: Total Sales, Total Profit, Units Sold and Profit Margin.
- Monthly sales trend analysis.
- Geographical sales analysis.
- Product-wise and retailer-wise performance.
- Interactive slicers and filters.

## Skills Demonstrated
- Data Cleaning and Transformation
- DAX Measures
- Data Visualisation
- Business Intelligence
- Dashboard Development
